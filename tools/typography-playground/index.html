Pricing Strategy Playbook

A escolha do modelo de pricing define toda a economia do produto: margem, velocidade de aquisição, perfil do cliente atraído e a viabilidade do crescimento.

17 Mai 2026 · 5 min de leitura · pricing strategy growth

Por que esse playbook existe

Pricing é decidido por intuição na maior parte dos casos. O resultado é margem espremida, cliente errado e canibalização interna. Este artefato compacta uma framework de decisão em 3 perguntas que apontam pra 1 dos 3 modelos clássicos.

Os três modelos

Cost-plus pricing

Preço = custo + margem fixa. Previsível, defensável, comum em hardware e serviços B2B com escopo claro. O trade-off: deixa dinheiro na mesa quando o valor percebido é maior que a margem padrão.

Value-based pricing

Preço ancorado no ROI ou economia gerada ao cliente. Margens altas, ciclo de venda mais longo, exige discovery profundo. Métrica-chave: % do valor capturado em relação ao valor entregue.

Penetration pricing

Preço baixo (até negativo) pra capturar marketshare rápido. Vence quando há network effects ou economia de escala. Risco: queima caixa pesado; depende de retenção e upsell pra LTV/CAC fechar.

Citação ilustrativa

"O preço é o feedback mais honesto que o mercado te dá sobre o valor que você cria. Tudo o mais é teoria."

Como implementar

  1. Mapeie seu custo unitário real
  2. Estime o valor gerado ao cliente
  3. Mapeie 3 concorrentes diretos e indiretos
  4. Decida o modelo via framework
  5. Teste com 3 tiers (baixo, médio, alto)

Code snippet

// Lifetime Value vs Customer Acquisition Cost
const ltvcac = (revenue, margin, churn, cac) => {
  const ltv = (revenue * margin) / churn;
  return ltv / cac;  // healthy if > 3
};

console.log(ltvcac(100, 0.7, 0.05, 200));  // 7.0
